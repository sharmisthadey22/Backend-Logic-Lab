# 🧪 Backend Logic Lab
A specialized repository for professional backend utilities, modular logic implementations, and mini-scale full-stack projects.

---

## 🚀 Key Modules & Features

### 📩 1. Email Automation Service
* *Tech:* Nodemailer
* *Logic:* Configured secure SMTP transport to trigger automated emails for user notifications.
* *Folder:* /Email-Automation

### 📤 2. File Upload System
* *Tech:* Multer
* *Logic:* Handled multipart/form-data for uploading images and documents with custom storage engines.
* *Folder:* /File-Upload-System

### 🛡️ 3. Data Validation Layer
* *Logic:* Server-side validation for User Registration (Email format, Mobile length, and Password strength) using custom logic and conditional checks.
* *Folder:* /Data-Validation

### 🛠️ 4. Mini Projects Portfolio
* *URL Shortener:* Backend logic for dynamic ID generation and URL redirection.
* *Weather & Currency Tools:* External API integration using Axios for real-time data processing.
* *Quiz & Todo Apps:* Logic for state management and JSON data handling.
* *Folder:* /Mini-Projects

---

## 🛠️ Tech Stack
* *Runtime:* Node.js
* *Framework:* Express.js
* *Database:* MongoDB
* *Tools:* Postman, Multer, Nodemailer, Dotenv, Axios.

---

## ⚙️ How to Run
1. Clone the repo: git clone <your-repo-link>
2. Install dependencies: npm install
3. Add your .env file.
4. Start the server: node index.js
